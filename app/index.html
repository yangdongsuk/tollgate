TollgatePay-per-call USDC channels on Arc
Arc mainnet

Let your agent pay per API call
without handing it your wallet.

Lock USDC in a channel for one API provider. Your agent signs a tiny off-chain voucher with every request, and the provider settles thousands of calls in a single transaction. The agent only holds a session key, so the most it can ever spend is the channel balance.

1 · OpenDeposit USDC, name the provider and a session key.
2 · CallEach request carries a signed running total. No gas, no wait.
3 · SettleThe provider redeems the latest total whenever it wants.
4 · CloseRequest close; after a grace period the rest comes back.
